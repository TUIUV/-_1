# صوتي (SawtiAssistant) — Flutter

مساعد صوتي عربي (فصحى + عراقية) للتحكم بالهاتف بدون Root. الواجهة والمنطق بـ **Flutter/Dart**، والوظائف التي تحتاج صلاحيات أندرويد الأصلية بـ **Kotlin** عبر Platform Channels.

- الجهاز المستهدف: Samsung Galaxy S22 Ultra، Android 16 (API 36)، `minSdk 26`.
- اسم الحزمة: `com.example.sawtiassistant`

## ⚠️ حالة الاختبار (صراحةً)
هذا المشروع **كُتب دون إمكانية تشغيل Flutter أو Gradle** (البيئة التي كُتب فيها لا تصل إلى Flutter SDK ولا pub.dev ولا Maven). لذلك:
- لم يُنفَّذ `flutter pub get` / `flutter analyze` / `flutter build apk` / `flutter test`، ولم يُبنَ APK.
- منطق تحليل الأوامر العربية جرى اختباره عبر نسخة Python مطابقة له، لا عبر Dart.
- لا يوجد ZIP مرجعي مرفق، فاعتُمد هيكل مشروع Flutter القياسي (Groovy Gradle).
- أول بناء قد يُظهر أخطاء بسيطة (إصدار Flutter/Gradle، تحذيرات)؛ أرسل نص الخطأ وأصلحه.

## البناء
**الطريقة الأسهل (GitHub Actions):** ارفع المجلد إلى مستودع GitHub؛ الملف `.github/workflows/build-apk.yml` يشغّل `pub get` ثم `analyze` ثم `test` ثم يبني APK، وتجده في Artifacts باسم `sawti-apk`.

**محلياً (Android Studio أو سطر الأوامر):**
```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --release     # أو --debug
# الناتج: build/app/outputs/flutter-apk/app-release.apk
```
المتطلبات: Flutter (stable حديث)، JDK 17، Android SDK Platform 36. ملفات `gradlew` و`local.properties` يولّدها Flutter تلقائياً. إن طلبت بيئة FlutterIDE إنشاء ملفات ناقصة فاستخدم `flutter create --platforms=android .` داخل المجلد (لا يستبدل ملفاتك).
الإصدار موقَّع بمفتاح debug ليُثبَّت مباشرة؛ للنشر الفعلي أنشئ مفتاحك.

## التثبيت والإعداد على الهاتف
1. ثبّت APK وامنح **الميكروفون** (والإشعارات).
2. من التطبيق اضغط «تفعيل» لخدمة التحكم؛ سيشرح التطبيق السبب ثم يفتح إعدادات إمكانية الوصول؛ فعّل «صوتي».
3. **مهم لـ APK خارج المتجر:** إن كان الخيار معطّلاً: إعدادات ← التطبيقات ← صوتي ← ⋮ ← «السماح بالإعدادات المقيّدة»، ثم أعد المحاولة.
4. للتعرف دون إنترنت: الإعدادات ← «التعرف على الكلام دون إنترنت» ← «فحص» ثم «تنزيل حزمة العربية» (Android 13+)، أو ثبّت العربية من خدمات Google ← الكلام.

## الهيكل
```
lib/
  main.dart                  نقطة الدخول
  theme.dart                 السمة (فاتح/داكن، RTL)
  models/                    voice_command, app_settings, speech_event
  services/
    command_service.dart     تحليل الأوامر وتنفيذها (المنطق الوحيد للأوامر)
    arabic_text.dart         تطبيع النص العربي واللهجة
    speech_service.dart      غلاف التعرف على الكلام
    wake_word_service.dart   كلمة التنبيه (مطابقة + تشغيل الخدمة)
    accessibility_bridge.dart جسر Kotlin (إمكانية الوصول، التطبيقات، الصلاحيات)
    assistant_controller.dart منسّق الحالة
    storage_service.dart     التخزين المحلي
  pages/                     home, command_history, settings
android/app/src/main/kotlin/com/example/sawtiassistant/
  SawtiApplication.kt        محرك Flutter مشترك يعيش مع العملية
  MainActivity.kt
  NativeBridge.kt            قنوات Dart↔Kotlin
  SpeechEngine.kt            SpeechRecognizer (محلي أولاً)
  WakeService.kt             خدمة أمامية (microphone) + إشعار إيقاف
  VoiceAccessibilityService.kt  رجوع/رئيسية/أخيرة/إشعارات/لقطة/تمرير
```
Dart يقرر ماذا يُنفَّذ؛ Kotlin ينفّذ الإجراء الأصلي فقط.

## الأوامر المدعومة (قابلة للتوسعة في `command_service.dart`)
ارجع، الرئيسية، التطبيقات الأخيرة، الإشعارات، الإعدادات السريعة، لقطة شاشة، انزل/اصعد (تمرير)، افتح الكاميرا، افتح أي تطبيق مثبت بالاسم، افتح Wi-Fi / الإنترنت / البلوتوث / الصوت / الشاشة / الوضع الداكن / الموقع / وضع الطيران / البطارية / الإعدادات. مثال: «يا مساعد افتح الكاميرا».
- الأمر غير المفهوم لا يُنفَّذ. التطابق التقريبي لاسم تطبيق يطلب تأكيداً (بالصوت «نعم/لا» أو بالأزرار). خيار «تأكيد كل أمر» متاح.
- التمرير: أُصلح اتجاه المشروع الأصلي (كان «انزل» يسحب للاتجاه المعاكس). عبارة «يا قمري» القديمة أُزيلت.

## كلمة التنبيه — كيف تعمل وقيودها
التنفيذ: خدمة أمامية تشغّل جلسات `SpeechRecognizer` محلية قصيرة متتالية، ويطابق Dart النص مع «يا مساعد» / «يا صوتي»؛ ثم يستمع للأمر، ينفّذه، ويعود للانتظار. **هذا ليس محرك Wake Word مخصصاً.**
- يستهلك بطارية أكثر؛ قد يصدر النظام صوتاً قصيراً مع كل جلسة.
- قد يوقفه النظام مع إطفاء الشاشة أو توفير الطاقة؛ استثنِ التطبيق من تحسين البطارية.
- يجب تفعيله والتطبيق ظاهر (قيد Android 14+ على خدمات الميكروفون)، ويُستأنف تلقائياً عند فتح التطبيق إن كان مفعّلاً. الخدمة لا تُعاد تلقائياً بعد إعادة تشغيل الجهاز.
- فتح التطبيقات/الإعدادات من الخلفية قد يمنعه أندرويد ما لم تكن خدمة التحكم مفعّلة.
- **بدائل أدق (لم تُعتمد):** Picovoice Porcupine (يحتاج AccessKey، ونموذج عربي مخصص، ترخيص تجاري/مجاني محدود)، أو Vosk (نموذج عربي كبير الحجم). اطلب ذلك إن أردت وسأوضح الحجم والترخيص قبل اعتماده.

## الخصوصية
- لا تسجيل ولا تخزين للصوت. يُحفظ نص الأوامر فقط (يمكن إيقافه ومسحه).
- التطبيق بلا صلاحية INTERNET (في الإصدار). التعرف عبر الإنترنت **اختياري ومغلق افتراضياً** بموافقة صريحة، ويتم عبر خدمة التعرف في النظام.
- خدمة إمكانية الوصول مضبوطة بدون قراءة محتوى الشاشة (`canRetrieveWindowContent=false`).
- زر «إيقاف الميكروفون فوراً» وزر «إيقاف» في الإشعار.
- لا يمكن تشغيل/إيقاف Wi-Fi أو البلوتوث مباشرة على Android الحديث؛ يُفتح الإعداد المناسب بدلاً من ادعاء ذلك.
